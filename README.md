# SpendArc

A Flutter offline-first finance tracker built for the Taghyeer Technologies Senior Flutter Developer assessment.

## Tech Stack
- flutter_bloc (Cubit)
- get_it
- ObjectBox

## Features
- Offline-first local persistence
- Simulated background sync
- CustomPainter Arc Meter
- Swipe to delete with undo
- Animated transaction list
- Dashboard analytics

## Architecture
Simplified Clean Architecture:
- data
- domain
- presentation
